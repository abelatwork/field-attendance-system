# Field Attendance System

A responsive web-based attendance tracking system for field students.

## Roles

- Student/User
- Supervisor
- Super Admin

## Main Features

- Student attendance check-in/check-out
- Automatic time recording
- Location capture
- Student management
- Supervisor attendance monitoring
- Super Admin management portal

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- Express
- PostgreSQL
- Prisma

## Project Structure

```text
frontend/   - React frontend
backend/    - Node.js/Express backend
docs/       - Project documentation
```
