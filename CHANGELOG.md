# Changelog

All notable changes to the Field Student Attendance System are documented in this file.

The project follows Semantic Versioning:

`MAJOR.MINOR.PATCH`

- **MAJOR** — Breaking or major architectural changes
- **MINOR** — New backward-compatible features
- **PATCH** — Bug fixes and small improvements

---

## [1.0.0] - 2026-09-17

### Added

- Initial Field Student Attendance System MVP.
- Student attendance recording using `IN` and `OUT`.
- Registered student search and selection.
- Browser-based location capture.
- Latitude, longitude, and location accuracy storage.
- Server-generated attendance timestamps.
- Duplicate `IN` prevention.
- `OUT` without active `IN` prevention.
- Student management.
- Supervisor management.
- Student-supervisor assignment.
- Supervisor attendance monitoring.
- Super Admin management functionality.
- JWT-based authentication for protected users.
- Role-based authorization.
- PostgreSQL database.
- Prisma database tooling.
- React and TypeScript frontend.
- Node.js, Express, and TypeScript backend.
- Initial project documentation.

### Documentation

- Added system requirements documentation.
- Added system design documentation.
- Added database design documentation.
- Added API documentation.
- Added user roles and permissions documentation.
- Added attendance rules documentation.
- Added development setup guide.
- Updated project README.
